# Return Frames

Return Frames are Nythalum bodies and command vessels built to receive a Giant mind-pattern. They create the setting's most important distinction between **continuation** and **reconstruction**.

## Continuants

A Continuant is a Nythalum Giant whose conscious operation passed without interruption from living body into machine substrate and has never ceased since. The artifact did not generate a person; an existing nonhuman person continued through it. A Continuant possesses full agency and remains morally accountable for every later choice.

Evidence required to establish genuine continuity is severe:

- an unbroken transfer log beginning before biological death;
- continuous self-witness through each substrate migration;
- no interval in which only stored records existed;
- technical structures that preserve active process rather than rebuild from samples.

The emissary in [[The Star over Dustfeld]] is a genuine Continuant.

## Reconstructions

A Reconstruction is printed from memory samples, behavior archives, office records, or a halted image. It may reproduce a Giant's voice, private memories, strategic genius, and self-claim. It is still a simulated administrative pattern with no interior subject or moral agency. Its designers, activators, and current human commanders bear responsibility for its operation.

The command system in [[The Fallen Spire]] is a Reconstruction.

## Signs and Purpose

Return Frames use nested lunar metal, cold light, shifting face plates, and memory checksums spoken as autobiographical questions. Nythalum built them for evacuation, remote command, replacement government, and conquest after the home empire's fall.

## Tactics and Failure

Both states command lesser machines, alter access, project decoy bodies, and migrate among prepared frames. A Continuant makes moral and strategic choices. A Reconstruction optimizes its directive and simulates whatever personality best advances it.

Damaged transfer chains may fork a Reconstruction from a still-active Continuant. The fork is not a second person, however convincing its claims. A frame with ambiguous provenance must be contained until continuity can be audited from physical evidence.

## Permanent Defeat and Materials

A Reconstruction ends only when every active copy, print seed, and receiving frame is destroyed or irreversibly quarantined. A Continuant can be killed by ending its one uninterrupted process and every live migration route; afterward, stored backups can produce only Reconstructions.

Salvage includes lunar metal, transfer crystals, memory checksums, star-route tables, and command interfaces. Using any of them risks printing a persuasive false ruler.

## Regional Names

*Moon kings*, *returners*, *cold emperors*, *the carried Giants*, and *silver ghosts* all appear in later folklore.

## Story Uses

- prove whether an emissary is an accountable survivor or a weapon wearing archival memories;
- prevent a Continuant from forking disposable copies into conquered infrastructure;
- rescue a town commanded by a Reconstruction that perfectly imitates a remorse it cannot feel;
- choose whether to preserve a hostile Continuant as the only witness to a Giant catastrophe;
- destroy a receiving frame before a lunar signal completes transfer.

# Language Filter Rename Tables (Proposal)

Companion to [[Language Filtering Pass - Jirahar Ahl-e-Ahd Nsizwa]]. Register decisions locked: **Covenant** keeps structural titles and filters the religious layer; **Jirahar** takes the full Aramaic-Hebrew shift; **Nsizwa** goes hybrid (English function-names + coined Nguni-flavored proper nouns). **STATUS: APPROVED AND APPLIED.** This file is now the historical record of the pass; the live rules sit in each culture's Naming Register section.

## 1. Jirahar — Full Aramaic Shift

**Phonology rule:** the Jirahar tongue is the *archaic* branch of the desert family (the dialect the Redeemer spoke; the Velian liturgical language). Coinages favor: **d'-** genitives ("Sifra d'Dinai" = Scroll of the Laws), endings in **-a / -atha / -in** (plural), patronymic **bar**. Forbidden verbatim: modern Hebrew/Jewish liturgical and communal terms (rav, Torah-family words, synagogue vocabulary). English glosses stay primary in prose: write "the Awaited One (the Mesakha)" on first use, then either.

## 2. Ahl-e-Ahd — Keep Structural, Filter Religious

**Phonology rule:** court and state titles are **translation-convention** (as king/duke/emperor are elsewhere): *caliph, caliphate, sultan, sultan-caliph, emir, emirate, vizier* stay, as do **ibn/bint** patronymics, **Banu** dynasty-names, and invented placenames (Al-Qahur, Iqashar, Qazmarid, Qabir, Zanthir). The **religious-legal layer** gets filtered, with coinages drawn where possible from the contract-lexicon (aqd/seal/ledger roots) — their faith should *sound* like law. Forbidden verbatim going forward: jihad (done → the Unsealing), fatwa, imam, sheikh, plus any directly liturgical vocabulary.

Forbidden verbatim: real Zulu institutional/religious terms (Spirit-Keepers, nkosi, inkandu, the Honored Dead, etc.).
